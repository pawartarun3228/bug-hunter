1. HOW TO RUN LOCALLY ON YOUR LAPTOP (FOR TESTING / VIDEO DEMO)
--------------------------------------------------------------------
Because your API key was safely removed from `main.py` using `os.getenv("GEMINI_API_KEY")`, run these two commands in your VS Code PowerShell terminal whenever you want to start the backend:

$env:GEMINI_API_KEY="paste_your_actual_api_key_here"
python main.py

Then double-click `index.html` in your folder to open the UI.

(Optional: If you want `http://127.0.0.1:8000` to open the UI directly inside VS Code's browser instead of showing `{"detail":"Not Found"}`, add this to `main.py`):
from fastapi.responses import FileResponse

@app.get("/")
async def serve_ui():
    return FileResponse("index.html")
